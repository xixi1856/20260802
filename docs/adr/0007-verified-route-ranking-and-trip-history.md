# ADR 0007：已核验风险路线排序与历史轨迹

## 决策

候选步行路线最多返回三条。高德 GCJ-02 折线用于高德地图展示，后端把折线转换为 WGS84 后再与 PostGIS 数据比较。路线只统计状态为 `VERIFIED` 或 `PROCESSING` 且已有社区最终风险等级的问题；同一问题在同一路线只出现一次。排序依次比较高、中、低风险问题数和路线长度，不生成总分。

确认票必须选择 `HIGH`、`MEDIUM` 或 `LOW`。最终等级取票数最多的等级；票数相同时依次优先 `HIGH`、`MEDIUM`、`LOW`。历史旧确认票没有等级，不根据上报者的 1～5 级 `severity` 猜测，需用户重新投票才参与等级汇总。

手机上传的行程轨迹保持 WGS84，并通过独立的历史行程、详情和轨迹分页接口读取。它不与高德推荐路线合并保存或解释。

## 运维边界

`DeviceAnalyticsProjectionConsumer` 保留。无人读取的行程风险和社区候选消费者已移除，已发布迁移创建的表暂时保留，避免升级时破坏历史数据。MQTT 的 Kafka 入口消费者只在 `MQTT_INGRESS_MODE=kafka` 时加载。

WARN/ERROR 日志使用独立 Fluent Bit → `blindway.application.logs.v1` → 归档消费者链路。采集器过滤低等级日志，消费者限制字段长度并清除凭据和精确坐标；归档默认关闭，通过 `LOG_ARCHIVE_ENABLED=true` 启用。

树莓派本地提醒程序与手机地图页面不在此仓库。本仓库的 MQTT 契约继续规定本地提醒不得等待网络；实际去重、距离、优先级和语音/振动逻辑必须在对应设备项目实现。
